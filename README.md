# ПродвижениеПро

Информационная система продвижения сайтов в сети интернет.

## Деплой на Railway

1. Создай новый проект на [railway.app](https://railway.app)
2. Подключи GitHub репозиторий с этим кодом
3. В настройках **Variables** добавь:
   - `ADMIN_PASSWORD` — пароль для входа в админку (по умолчанию `admin2024`)
   - `PORT` — Railway выставит автоматически

## Локальный запуск

```bash
npm install
npm start
```

Сайт будет доступен на http://localhost:8008

## Страницы

- `/` — главная страница сайта
- `/admin` — административная панель

## Вход в админку

- Логин: `admin`
- Пароль: значение переменной `ADMIN_PASSWORD` (по умолчанию `admin2024`)

## Функционал

- Адаптивный сайт с бургер-меню
- Интерактивный калькулятор стоимости услуг
- Форма заявок с сохранением в базу данных
- Административная панель: управление заявками и клиентами
- Экспорт заявок в CSV

## Стек

- Node.js + Express
- SQLite (база данных сохраняется в файл `seo-promo.db`)
- Vanilla JS + CSS на фронте
